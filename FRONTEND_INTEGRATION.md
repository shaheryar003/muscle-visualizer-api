# Frontend Integration Guide

## Base URL

All requests go to your deployed API base URL, e.g.:

```
https://your-service.onrender.com
```

All endpoints are prefixed with `/api/v1/`.

---

## Muscle Visualizer Endpoints

These endpoints wrap the Muscle Visualizer RapidAPI.

---

### GET `/api/v1/muscles`

Returns the list of all available muscle names you can pass to the visualize endpoints.

**Query params:** none

**Response:** JSON array of muscle name strings.

---

### GET `/api/v1/visualize/muscles`

Returns a JPEG image of a body diagram with the specified muscles highlighted.

**Query params:**

| Param | Required | Description |
|-------|----------|-------------|
| `muscles` | Yes | Comma-separated muscle names, e.g. `biceps,triceps` |
| `color` | No | Hex color code for the highlight, e.g. `#ff0000` |

**Response:** JPEG image (`Content-Type: image/jpeg`). Render directly as an `<img>` src or blob URL.

---

### GET `/api/v1/visualize/heatmap`

Returns a JPEG heatmap image where each muscle can have its own color intensity.

**Query params:**

| Param | Required | Description |
|-------|----------|-------------|
| `muscles` | Yes | Comma-separated muscle names, e.g. `biceps,triceps` |
| `colors` | No | Comma-separated hex colors matching each muscle in order, e.g. `#ff0000,#00ff00`. Can also be a single global color. |

**Response:** JPEG image.

---

### GET `/api/v1/visualize/workout`

Returns a JPEG image showing primary (target) and secondary muscle activation for a workout.

**Query params:**

| Param | Required | Description |
|-------|----------|-------------|
| `targetMuscles` | Yes | Comma-separated primary muscles, e.g. `biceps` |
| `targetMusclesColor` | Yes | Hex color for primary muscles, e.g. `#ff0000` |
| `secondaryMuscles` | No | Comma-separated secondary muscles. Defaults to `none` if omitted. |
| `secondaryMusclesColor` | No | Hex color for secondary muscles. Defaults to `#000000` if omitted. |

**Response:** JPEG image.

---

## ExerciseDB Endpoints

These endpoints wrap the ExerciseDB RapidAPI. All return JSON.

---

### GET `/api/v1/edb/muscles`

Returns all muscle groups available in ExerciseDB.

**Query params:** none

---

### GET `/api/v1/edb/equipments`

Returns all equipment types available in ExerciseDB.

**Query params:** none

---

### GET `/api/v1/edb/exercisetypes`

Returns all exercise type categories.

**Query params:** none

---

### GET `/api/v1/edb/exercises/search`

Search exercises by a keyword.

**Query params:**

| Param | Required | Description |
|-------|----------|-------------|
| `search` | Yes | Search term, e.g. `curl` |

---

### GET `/api/v1/edb/exercises`

List exercises with optional filters.

**Query params:**

| Param | Required | Description |
|-------|----------|-------------|
| `name` | No | Filter by exercise name |
| `keywords` | No | Filter by keywords |

---

### GET `/api/v1/edb/exercises/{exercise_id}`

Get full details for a single exercise by its ID.

**Path params:**

| Param | Description |
|-------|-------------|
| `exercise_id` | The exercise ID string returned from a list/search call |

---

## Notes

- Image endpoints return raw JPEG bytes. To display them, either set the URL directly as an `<img>` `src`, or fetch as a blob and create an object URL.
- Muscle names must exactly match the values returned by `/api/v1/muscles` — use that endpoint to populate dropdowns.
- CORS is open (`*`), so requests from any frontend origin are accepted.
- The API docs (auto-generated by FastAPI) are available at `{BASE_URL}/docs` for interactive testing.
